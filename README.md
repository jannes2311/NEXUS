# NEXUS – dein KI-Sprachassistent für Windows

Sag „Nexus“ und dein PC hört zu. Nexus öffnet Programme, regelt Lautstärke und Helligkeit, sucht im Web und in deinen Dateien, verwaltet Termine, steuert Spotify und merkt sich, was dir wichtig ist – alles per Sprache.

## Installation

1. `Nexus_Setup.exe` herunterladen und starten.
2. Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“. Das passiert bei neuen Programmen ohne Signatur. Klick auf **Weitere Informationen → Trotzdem ausführen**.
3. Der Installation folgen. Nexus findest du danach im Startmenü und auf dem Desktop.
4. Beim ersten Start lädt Nexus die Spracherkennung herunter (einige hundert MB). Das passiert nur einmal.

## Voraussetzungen

- Mikrofon (am besten ein Headset)
